# 0.5.1 Windows 多分片恢复实验版

本次提供 Windows x64 安装 EXE、便携 ZIP 和 `SHA256SUMS.txt`。安装包内置 Python 3.14.10、SQLCipher 4.5.2 community 及许可；无需自行安装 Python 或配置 DLL。

- Windows 识别全部现有 `message_N.db` 编号分片，按各库的身份映射解析消息，跨分片去重与拒绝冲突。导出、候选、DB/WAL/SHM 原件、应用回撤和双向撤回使用完整清单，不自动新建分片。
- Windows 新结构配置转换所有正 int64 消息类型的明确 packed 方向字段，保留原始内容与非文本本地状态。未知方向、结构不兼容或没有真实正消息编号时仍拒绝，不伪造编号。
- A 核验并退出后再登录 B。**此时从手机 B 将与 A 的聊天导入电脑微信 B**；电脑 B 已完整保留时直接核对。本人确认电脑 B 的所需单聊内容和时间范围完整后，才允许读取 B 和生成预览。更换账号、密钥或重新登录会清除确认。
- 修复目标跨分片相同副本误判冲突、撤回原件清单越界、Windows 备份刷新兼容性和大量资源逐条全表扫描的问题。
- 合并 Mac 0.5.0 源码中的语音/附件实验功能，保留其单分片恢复、显式模式与媒体校验；本次不提供新版 Mac 二进制包。

这是实验版。Windows 本次覆盖消息条目和明确结构的方向转换，**不搬运附件本体**，不宣称语音可播放、图片/视频/文件可打开。真实 Windows GUI 恢复、各类型微信显示和独立手机迁移仍未验收。Mac 媒体 v2/v3 bundle 不由 Windows 处理。
