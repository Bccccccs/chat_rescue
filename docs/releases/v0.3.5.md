# Chat Rescue 0.3.5 · 五步桌面向导（本机实验版）

本版提供原生 Mac 界面，把双方授权单聊互相补齐组织成五步流程：准备软件、登录两个账号、读取双方聊天、确认补齐预览、检查恢复结果。

![五步流程示意](https://raw.githubusercontent.com/Bccccccs/chat_rescue/v0.3.5/docs/images/desktop-workflow.svg)

## 下载

Apple Silicon 用户下载本页附件 `Chat-Rescue-0.3.5-macOS-arm64.zip`，解压打开 `Chat Rescue.app`。内置 Python 与 SQLCipher；取钥仍需 Xcode Command Line Tools / Apple LLDB。包面向 macOS 14+，实测环境为 macOS 27.0 / 微信 4.1.13；尚未完成 Apple 开发者公证。

## 本版内容

- 固定 A/B 微信副本、独立 B 数据目录、权限路径复制与访达定位。
- 四库验证、本人昵称识别、自动读取与双向新增/重复数量预览。
- 确认后协调写入、原件备份、部分失败回执、历史任务续接。
- 双方库未变化时允许完整任务撤回，已有新消息时拒绝覆盖。
- README 增加五步操作图示、桌面使用说明和支持边界。

## 验证与限制

本机 61 项合成测试通过，桌面包通过构建与代码签名校验。截图展示读取与预览，不作为真实双账号应用、客户端显示或手机迁移验收凭证。

仅支持微信 4.1.13、单个 message_0.db、双方授权单聊中的文本/名片/文件消息条目。附件本体不恢复，不自动同步到服务器或手机。请先核对预览，应用后在微信里检查内容、时间和收发方向。
