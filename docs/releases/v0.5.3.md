# 0.5.3 Windows B → A 单会话替换实验版

本版桌面流程只用 B 与 A 的单聊记录重建 A 中与 B 的会话，不再生成 A → B 的补齐候选。B 是唯一聊天来源，B 不应用写入。沿用 0.5.2 的 4.2.x.x 版本准入、多分片、真实编号和完整性保护。

- 先在独立副本中移除 A 的所选会话及对应资源，再按 A 的身份映射导入 B 的会话。A 其他会话、联系人、稀疏编号和本地草稿保留。A 原会话不作为源消息解析，因此其中的方向异常不会阻塞 B 的导出。
- 明确暂不导入 B 会话中的类型 **10000、10002**，预览按类型统计数量。本次不适配这些条目，不把其他未知方向、未知发送者或结构异常直接当作中立消息忽略。
- 预览明确列出 A 将移除的条数、从 B 导入的条数、暂不导入条数、双方身份与原件目录。替换会移除 A 独有的该会话消息；确认具体计划后才应用。只生成候选不会修改真实库，不要人工先删聊天。
- B 的普通消息方向异常时，显示实际值、预期值、类型及配置，拒绝生成可应用计划。保留真实消息编号、冲突拒绝、全部分片 DB/WAL/SHM 原件、应用前哈希、失败回撤和无后续变化时的撤回。
- 旧版双向任务可以载入查看，0.5.3 桌面不提供应用旧双向计划的按钮；CLI 原有双向模式保持原行为。
- 替换使用独立 v4 协调清单，旧版客户端会拒绝载入，避免将删除型预览误当作普通新增补齐。

## 下载与升级

关闭旧版 Chat Rescue 后安装 `Chat-Rescue-0.5.3-Windows-x64-Setup.exe`；或把便携 ZIP 完整解压到新目录，运行其中的 `ChatRescue.exe`。确认左下角显示 **0.5.3**。私有任务、密钥、原件和微信记录保留；不混用旧 EXE、后端和运行时。

核验本次 A、B 身份与完整密钥回执，正常退出全部微信，再生成新的 **B → A 替换预览**，核对具体条数及方向后决定是否应用。不复用旧计划的确认。

## 验证边界

这是未签名的 Windows x64 实验预发布，仅提供 Windows 二进制，Mac 下载仍为 0.5.0。本版没有新增真实取钥、微信显示或手机迁移的验收证据，4.2.0.13 的实际消息兼容性仍需以本机具体候选校验为准。非文本消息条目不代表附件本体可播放或打开；Windows 不搬运附件本体。开发与打包不操作真实聊天库。
