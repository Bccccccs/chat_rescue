# 0.3.6 · Windows 实验版

首次提供 Windows x64 安装包与便携包，内置 Python 3.14.10、SQLCipher 4.5.2 community 和后端。安装后使用开始菜单或桌面快捷方式，无需手动配置 Python、DLL 或源码路径。Mac 已发布的 0.3.5 仍从原 Release 获取，本次不提供新的 Mac 二进制。

- 登录顺序改为先 A、读取核验并正常退出，再 B，每次只打开一个原版微信。
- 可用独立私有工作目录重现首次使用；账号、密钥和昵称不从旧实验隐式读取。
- 修复中文 Windows 的 GBK/UTF-8 管道问题，中文路径、昵称与表情完整传递。
- 依据本机证据适配 4.2.0.12 文本的发送/接收方向和状态；去重、冲突、四库及 DB/WAL/SHM 校验保留。
- 安装器支持当前用户安装、开始菜单、可选桌面快捷方式和卸载；用户资料与程序分离，卸载保留密钥、任务、备份与微信记录。

## 下载

- `Chat-Rescue-0.3.6-Windows-x64-Setup.exe`：推荐，Windows 安装向导。
- `Chat-Rescue-0.3.6-Windows-x64-Portable.zip`：解压后打开 `ChatRescue.exe`，保留所有配套文件。
- `SHA256SUMS.txt`：两个下载文件的 SHA256 校验值。

要求 Windows 10 build 19041+ / Windows 11 x64、.NET Framework 4.8+。安装器检查 .NET，缺失时提示由本人从 Microsoft 官方渠道修复。运行依赖随包提供，不更改全局 PATH。安装包尚未进行项目代码签名，系统可能提示未知发布者或阻止运行；不要求关闭安全功能。

## 验证和限制

本机已验证两个 4.2.0.12 账号的取钥、四库导出及配对文本方向；三条带明确实验标记的文本完成副本恢复、源账号经确认后的本地写入及重新导出核对，目标仅生成预览。包内运行时检查、中文目录安装、安装版 GUI 启动、卸载与用户资料保留通过。

真实双账号 GUI 应用、微信显示、手机迁移、完全空白库初始化及干净虚拟机的完整验收仍待完成。Windows 当前仅核验 4.2.0.12 文本，名片/文件类型继续拒绝。合成消息未真实发送，附件本体不恢复，不自动同步到服务器或手机。
