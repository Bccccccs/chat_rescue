# Chat Rescue 0.3.7 · Mac 顺序登录向导（实验版）

Mac 新版按“打开 A → 登录并确认 A → 打开 B → 登录并检查旧聊天 → 读取及预览”引导，每次只展示当前需要完成的操作。

## 下载与安装

下载 `Chat-Rescue-0.3.7-macOS-arm64.zip`，解压，把 `Chat Rescue.app` 拖到“应用程序”。详细步骤见 [Mac 安装与跨电脑使用](https://github.com/Bccccccs/chat_rescue/blob/v0.3.7/docs/macos-deployment.md)。`SHA256SUMS.txt` 提供下载校验值。

要求 Apple Silicon（M 系列）、macOS 14+；本机实测 macOS 27.0 / 微信 4.1.13，最低构建版本不代表所有系统均已实测。取钥仍需 Xcode Command Line Tools / Apple LLDB；Python 与 SQLCipher 随包提供。应用为本地临时签名，尚未完成 Apple 公证。

## 本版改进

- 启动时只打开 A；确认 A 后才打开 B。B 必须人工确认在电脑副本中看到了需要恢复的旧聊天，才能继续读取。
- 未完成的步骤暂不可进入，账号修改可以重新开始检查；首次准备完成留在权限页。
- 启动前检查原版微信，发现运行冲突时直接提示用 ⌘Q 正常退出，无需重新准备副本。
- 结果页分别打开 A、B，更新新手指南；自动识别“应用程序”中微信的中文或英文应用名。
- 保留远端 Windows 0.3.6 的源码、文档及发布包。本次仅提供新版 Mac 二进制，Windows 用户仍从 [0.3.6](https://github.com/Bccccccs/chat_rescue/releases/tag/v0.3.6) 下载。

## 验证与边界

本次 macOS 本机 118 项测试：105 项通过、13 项因平台限制跳过；Swift 状态机测试及加密集成测试通过。Mac 包构建、签名及下载哈希核对通过。此前原版退出后已确认 A 副本保持运行并显示登录窗口；不代表真实双账号恢复应用、客户端内容或手机迁移已验收。

应用包不含开发机账号、密钥、聊天库或任务。仅支持已验证微信版本、单个 message_0.db 与授权单聊中的受支持消息条目。附件本体不恢复，不自动同步到服务器或手机，身份和具体预览仍需本人确认。
