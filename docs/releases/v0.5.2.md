# 0.5.2 Windows 4.2 版本准入修复实验版

本次基于 Windows 0.5.1 发布，提供内置 Python / SQLCipher 的安装 EXE、便携 ZIP 和 SHA256 校验文件；不提供新版 Mac 二进制包，Mac 当前下载仍为 0.5.0。

- 程序检查、实验取钥及恢复导出的取钥回执接受完整 **4.2.x.x**，解除必须为 4.2.0.12 的版本拦截。
- 保留 0.5.1 的多消息分片、structured 方向转换及 B 读取前手机导入确认。配置标识保持兼容，实际消息方向、未知结构、账号绑定、全部数据库完整性、真实消息编号冲突、DB/WAL/SHM、应用前哈希及失败回撤检查继续执行。
- 改善方向冲突报错，提示核对配套 `.capture.json` 和旧导出配置。导入已有密钥的界面增加配套回执说明；缺失回执的旧输入不自动猜测方向。

## 更新方法

关闭远端电脑上的 Chat Rescue，安装 `Chat-Rescue-0.5.2-Windows-x64-Setup.exe`；已有私有任务、密钥、原件和微信数据保留。使用便携版时解压到新目录，运行整套程序，不只替换 EXE 或混用旧后端。打开后左下角应显示 **0.5.2**。

确认双方账号与配套回执，重新核验并生成新预览。保留旧任务，不修改旧回执、版本号或计划。本人确认的是本次生成的具体应用计划；更新本身不会应用聊天恢复。

## 验证边界

版本准入放宽不代表所有 4.2 版本已经实机验证。已有真实方向证据仍仅覆盖 4.2.0.12 文本；其他完整版本及非文本结构转换仍需独立验收。Windows 不搬运附件本体，不保证语音播放或图片、视频、文件可打开。真实 GUI 恢复、各类型客户端显示及手机迁移仍未完成验收。

安装包仍为未签名的实验预发布。本次开发和打包不启动微信、不实际取钥、不操作真实聊天库。
