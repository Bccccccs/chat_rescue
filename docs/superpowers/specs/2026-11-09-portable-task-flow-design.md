# Windows 普通模式流程整合与任务迁移设计

状态：用户已批准直接实施。2026-11-09。

## 目标与已确认约束

用户要减少反复试错，换电脑解压即用，并能继续任务。保留普通 Windows 用户环境，不创建用户、不加沙盒；来源和目标自由选择，无账号与占用 PID 绑定，无互换按钮。媒体缺条件或格式未适配时跳过本体、保留消息和原因计数。数据库验证、真实身份、分片路由、原件、哈希和具体应用确认不放宽。

本次是代码维护，不启动微信、不实际取钥、不读写真实聊天库。程序副本不能承诺隔离当前 Windows 用户的微信缓存。

## 方案

建议沿用已验证恢复引擎，增加清楚的读取状态和任务迁移层。单纯改文案不能解决路径依赖；重写引擎会扩大方向、备份和回撤风险，没有必要。采用这一方案是本设计的建议，尚待用户确认。

## 三个主步骤

1. **准备并读取账号**：环境自动检查并展示结果；目标与来源可任意顺序登录、读取。登录与读取分开标明。依次显示未读取、读取中、验证失败、已验证；只有全部必要库与本人身份通过才显示已验证。失败保留本卡片错误与脱敏诊断入口，不清除另一账号成果。只有一个完整候选目录时可预选，但仍待本人确认；多个目录列为待识别，不能按时间、目录编号或进程占用猜账号。高级区域保留目录、密钥和手工选择入口。来源聊天完整性确认保留。
2. **检查恢复预览**：双方身份确认后，退出微信，一次执行所有必要库、结构、方向、分片和媒体检查。显示目标移除、来源导入、暂不导入和媒体跳过原因及数量。失败按阶段给出可操作提示；原件路径始终可打开。旧或无效预览须重新生成。
3. **确认并检查结果**：本人确认具体预览后应用；数据库回执、电脑显示和手机验收分开。历史/中断任务不能重复应用；撤回继续沿用既有检查。

三步是主导航合并，不删减引擎检查。程序安装/源码构建/模拟报告不占主流程，移入帮助或高级入口。用户任务状态不得因刷新、角色重选或失败丢失。

## 换电脑接续

用户随后覆盖决定：包内不带微信，不要求卸载或重装，使用本机腾讯官方微信。程序运行时、SQLCipher、后端和离线教程均包内相对定位；本机微信路径逐机检查。私有工作区默认仍在当前用户目录，避免把资料写入解压包或只读盘；界面直接显示位置并提供“打开工作区”。

新增“导出接续任务”与“载入接续任务”，转移的是独立私有任务目录，不是直接压缩整个工作区。清单版本化，按相对路径列出必要任务资料和逐文件哈希；只收纳所选任务的账号验证材料、已导出单聊、预览、原件和回执，不能递归带入其他任务、账号资料或整个微信目录。导出前明确包含私人聊天和密钥，需本人私密保管。复制过程不修改原资料。

接续仅用于同一授权操作者换机，不用于把整套资料交给另一参与者；跨参与者单聊 bundle 仍使用原有独立流程。新增任务索引关联两侧分散的读取 job、所选媒体选项与预览。支持仅读完一侧、两侧已读但尚无预览、预览失败及已有应用回执的阶段；失败读取只保留失败状态和脱敏报告，不制造有效密钥。尚未产生任何资料的空任务无需导出。

载入到新的唯一私有目录，拒绝链接、越界、重复/大小写冲突、缺失和哈希不符；收紧当前用户 ACL。原回执、应用/中断标记和旧路径原样保存为历史证据，不能改写成新电脑验证成功。

新电脑显示“待重新定位/核验”，本人选择当前电脑目标和来源数据库。本轮继续要求双方数据库在新电脑可访问并重新核验；任务接续包不代替微信官方的数据迁移，缺少一侧实库时提示完成该侧准备，保留已完成阶段。沿用已有密钥时，仍重新执行全部必要库 HMAC、完整性与身份检查；通过才生成绑定新目录的独立验证回执，带旧材料摘要作为来源记录。缺少数据库或校验不通过时保留历史，可重新读取，不静默选其他账号。旧源单聊 bundle 保留为历史资料，本轮不新增仅凭 bundle 执行桌面替换的入口。

换电脑的旧候选只能查看，不直接应用。确认新路径和身份后生成新预览。迁移任何有应用、中断或回撤回执的任务，只展示历史状态；不得通过重新定位把同一次应用恢复为“未执行”。后续确需恢复时必须创建明确的新任务。原电脑原件不能冒充新电脑的可撤回备份。

## 账号识别故障与媒体

现有截图表明全库 HMAC 未完成，尚不能确定是目录、未捕获密钥还是客户端布局问题。保留最新读取覆盖统计和失败阶段诊断，不输出密钥、盐、内存地址或账号标识；合成测试通过不能宣称现场问题已修好。

继续保留已有 Windows 图片/音视频容器、DAT 可验证证据、多 media_N.db 与空媒体库改进。未知格式和缺媒体条件按已确认规则跳过；已有库坏密钥、未知结构、身份冲突或哈希变化仍停止。不把识别格式写成实际播放已验收。

## 验证与交付

使用合成材料测试读取失败/成功、任意顺序、历史不覆盖、迁移路径改变、ACL、文件篡改/链接越界、旧回执不可重写、已应用/中断任务不可重复应用，以及媒体分片/跳过和备份回撤。编译 WPF，检查相对路径包、中文/空格路径和离线教程链接。整合包只在这些检查完成后交付一次，附版本与校验值；现场登录、媒体打开和新电脑实际验收单独记录。

文件组织、清单细节、合成测试布局等由实现者决定；不得改变以上身份和应用边界。现有未提交修改全部保留，本设计不授权提交或发布正式版本。
