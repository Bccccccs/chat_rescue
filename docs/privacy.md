# 隐私与密钥

本工具用于双方授权的聊天记录恢复。B 的数据库属于 B，A 的数据库属于 A；B 只提供双方约定的单聊记录，A 只在自己的本地账号上应用。

## 每种文件都需要保管

| 文件 | 风险与处理 |
| --- | --- |
| `*-keys.json` | 可以解密匹配的微信库；只留在所属账号本机，权限建议 `600` |
| 微信原库、DB/WAL/SHM 和备份 | 含账号资料与聊天数据；保留原件，不提交 Git |
| `source-plain` | 明文整库，可能包含其他联系人和会话；不得分享给 A |
| `chat` bundle | 不含密钥，但含单聊正文、参与者映射和资源元数据；只向授权的 A 私密分享 |
| 恢复计划、候选和报告 | 可能包含数据库副本、身份信息或消息细节；同样按私有聊天资料保管 |
| 调试副本 | 只用于取钥，保留原版；使用结束后可撤销权限并清理副本 |

在创建工作目录前设置 `umask 077`，并把目录权限设为 `700`。权限限制的是本机文件访问，不能防止拥有相应账号权限的程序、云盘或备份软件读取资料。工作目录应放在双方确认的私人位置。

## 分享规则

只分享 `save-chat` 产生且已核对参与者的单聊 bundle。不要发送密钥、完整明文库、整个微信目录或整个恢复工作目录。bundle 是明文数据；tar/gzip 压缩与 base64 编码不提供保密性，选择双方信任的私密传输方式。

文件消息条目可能包含资源路径或描述，但工具不自动下载附件。分享前检查这些元数据是否也在授权范围内。

## 公开反馈

Issue、PR、终端截图和日志都可能泄露聊天信息。公开反馈仅保留环境版本、命令名、脱敏的错误类型和操作步骤。移除账号 wxid、联系人昵称、真实目录、手机号、聊天正文、数据库片段和密钥。不提交真实资料作为测试 fixture。

验收前保留可回撤原件；验收后双方决定资料保留期限和清理方式。不要以删除原始消息作为恢复准备步骤。
